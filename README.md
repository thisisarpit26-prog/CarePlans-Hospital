# 🏥 CarePlans Hospital

A responsive, multi-page hospital website built with pure **HTML & CSS** as a student frontend development project.

---

## 📌 About

CarePlans Hospital simulates a real hospital's online presence — covering services, diagnostics, a disease encyclopedia, care plans, and appointment booking. No frameworks or backend involved.

---

## ✨ Features

- Fixed glassmorphism navbar with smooth anchor navigation
- Full-screen hero section with Book Appointment CTA
- Hospital services & diagnostics cards (with hover animations)
- **Diseases A–Z** — 26 pages covering 78+ diseases, each linking to Wikipedia
- Care plans pricing section (3 tiers)
- Appointment booking form
- Fully responsive using CSS Grid & Flexbox

---

## 🛠️ Tech Stack

`HTML5` &nbsp; `CSS3` &nbsp; `CSS Grid` &nbsp; `Flexbox` &nbsp; `Font Awesome` &nbsp; `AVIF/JPEG Images`

---

## 🗂️ Project Structure

```
CarePlans hospital/
├── index.html          # Main homepage
├── A.html – Z.html     # Disease encyclopedia pages (26 files)
├── careplane.css       # Main stylesheet

```

## 💳 Care Plans

Three demo subscription tiers — OPD Care Plan, Diagnostic Plus, and Wellness Plan — with placeholder pricing for UI demonstration purposes.
